# Предмет проекта

Rutony ODA Bridge нужен пользователю RutonyChat, который получает донаты
через ODA и хочет передавать их обычным оповещениям и скриптам программы.
Мост работает внутри RutonyChat через автономный C#-скрипт и .NET 9 библиотеку.
Управление и OAuth доступны в обычном браузере через IPv4 loopback-панель.

Мост принимает HistoryItemEvent типа `payment` от выбранных систем: ODA,
DonationAlerts, DonatePay, DonatePay.eu, Donate.Stream, DonateX и Tribute.
По умолчанию включена только ODA. Галочки выбирают уже поступающие в ODA
события; они не подключают сторонний сервис к ODA. Пустой выбор разрешён.
Сохранение выбора ставит приём на паузу и сохраняет OAuth.

Передаются имя, сумма с точностью до копейки, валюта, сообщение и стабильный
идентификатор. Повтор подтверждённого ID подавляется по собственному журналу.
Неопределённый результат требует явного решения оператора. Полная история
до подключения не импортируется; срок хранения очереди — 24 часа.

Своё OAuth-приложение создаёт пользователь. Windows DPAPI защищает реквизиты
и токены текущего Windows-пользователя. Мост не принимает пароль ODA и не
использует встроенные ключи чужого приложения.

Автоматические тесты проверяют локальные контракты на имитаторах.
Настройки OAuth и права доступа зависят от приложения пользователя.
Exactly-once между диском и native API не гарантируется. Общей дедупликации
с другими независимыми входами того же сервиса нет.
