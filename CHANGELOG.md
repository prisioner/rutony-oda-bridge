# Changelog

## 1.0.0 — 2026-11-06

- Первый MVP-выпуск: доставка донатов ODA в штатные Donate-события
  RutonyChat для оповещений и пользовательских скриптов.
- OAuth через приложение пользователя, локальная панель, выбор исходных
  сервисов, защита от повторной доставки и хранение секретов через DPAPI.
- Отдельные комплекты ручной установки и Steam Workshop.
- Собственный RabbitMQ, .NET SDK и Node.js для готового пакета не требуются.
