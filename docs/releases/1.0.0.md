# RutonyOda 1.0.0

Первый MVP-выпуск моста ODA для RutonyChat. Выбранные платежи передаются
в штатные Donate/OnDonate-события с именем, суммой, валютой и сообщением.

## Возможности

- OAuth через собственное приложение пользователя и защита секретов Windows DPAPI.
- Локальная панель управления, статус связи, выбор источников и пауза передачи.
- Защита от повторной доставки и явное разрешение неопределённого результата.
- Ручной пакет с установщиком и восстановлением, отдельный комплект Steam Workshop.

## Установка и обновление

Следуйте [инструкции подключения](../oda-setup.md). Используйте один активный
пресет расширения. Настройки, реквизиты и журнал хранятся отдельно от файлов
пакета; обновление их не заменяет. После замены DLL полностью перезапустите
RutonyChat. Установщик и восстановление описаны в
[руководстве по поставке](../project/delivery.md), состав Workshop-комплекта —
в [техническом руководстве](../workshop/README.md).

## Ограничения

Требуются Windows, совместимый RutonyChat с .NET 9 runtime и своё
OAuth-приложение ODA. Готовому пакету не нужны .NET SDK, Node.js и собственный
RabbitMQ. Совместимость со всеми версиями RutonyChat и всеми вариантами
подключённых сервисов не гарантируется.

Полная история до подключения не импортируется; срок хранения очереди —
24 часа. Общей дедупликации с независимыми входами того же сервиса нет.
При неопределённом результате повтор может повторить оповещение.
Загрузка, подписка, обновление и отписка через Steam Workshop требуют
проверки в конкретной установке; автоматические тесты используют имитаторы.
