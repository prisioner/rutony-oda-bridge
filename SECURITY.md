# Сообщения о безопасности

Не помещайте токены, Secret, OAuth code/state, OBS password, credentials,
пользовательские журналы или личные идентификаторы в публичные issues,
коммиты, screenshots и CI-логи. Передавайте минимальное воспроизведение
с вымышленными данными, версией расширения, SHA и описанием последствий.

Если в GitHub этого репозитория включён private vulnerability reporting,
используйте **Security → Advisories → Report a vulnerability**. Наличие
этой возможности не предполагается автоматически. Если кнопки нет,
не открывайте публичный issue с деталями уязвимости: владелец должен
сначала выбрать и объявить приватный канал. Этот документ не задаёт email,
срок ответа, SLA или обещание поддержки.

При подозрении на раскрытие действующего секрета отзовите/замените его
в соответствующем сервисе. Удаление файла из последнего commit не удаляет
его из истории. Сохраните необходимую локальную информацию для разбора;
не переписывайте общую историю и не публикуйте значения без согласования.

За совместимость расширения, собственные зависимости и обработку данных
отвечает проект расширения. Runtime и обновления закрытого RutonyChat
находятся в ответственности его поставщика. Гарантированный диапазон
поддерживаемых vendor builds не заявляется без ручного прогона; текущие
факты — в [совместимости](docs/runtime-compatibility.md).
Выпуски предоставляются по [MIT](LICENSE), без гарантий; фиксированного
периода сопровождения и обязательств по исправлению старых версий нет.
