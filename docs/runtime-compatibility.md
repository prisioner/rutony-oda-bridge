# Совместимость Rutony ODA Bridge с .NET runtime

Расширение собирается для net9.0 и загружается внутрь RutonyChat;
runtime самого приложения определяет исполнение. Переключение TargetFramework
расширения на net10.0 не обновляет host.

## Контракт совместимости

Основной пакет рассчитан на SDK и runtime RutonyChat для .NET 9.
Компиляция тонкого скрипта против SDK проверяет сигнатуры API,
а синтетические core/native тесты — поведение в изолированном процессе.
Эти проверки не заменяют загрузку расширения в выбранную сборку RutonyChat.

| Host | Библиотека расширения | Условие |
|---|---|---|
| RutonyChat на .NET 9 | net9.0 | Основной целевой SDK и формат пакета |
| Изолированный test host | net9.0 | Можно проверить на явно выбранной установленной версии runtime |
| RutonyChat на другой major runtime | net9.0 | Нужны совместимый SDK, компиляция и ручная проверка загрузки |
| RutonyChat на .NET 9 | net10.0 | Такой пакет не поставляется |

## Изолированная проверка runtime

Нужны .NET SDK из `global.json`, установленные runtime и Node.js.
Команды выполняются из этого клона, без рабочего RutonyChat или аккаунта:

```powershell
./scripts/build.ps1 -Check
dotnet --list-runtimes
./scripts/check-runtime-compatibility.ps1 -RuntimeVersion '<полная версия runtime>'
```

Выберите полную версию из `dotnet --list-runtimes`. Должны присутствовать
все frameworks тестового приложения этой версии. Checker создаёт только
копии runtimeconfig в `.runtime` и запускает собранные синтетические
core/native проверки. Он не устанавливает runtime, не меняет системные
переменные, не запускает RutonyChat и не редактирует его конфиг.
CLI roll-forward Disable обеспечивает запуск на запрошенной версии.
Временные файлы остаются в игнорируемом каталоге для проверки результата.

## Обновление host

Используйте поддерживаемую поставщиком сборку RutonyChat и актуальные
security patches её runtime.
[Политика поддержки Microsoft](https://dotnet.microsoft.com/en-us/platform/support/policy/dotnet-core)
и [правила выбора runtime](https://learn.microsoft.com/en-us/dotnet/core/versions/selection)
описывают сроки поддержки и roll-forward. Расширение не продлевает
поддержку runtime приложения.

Перед переходом на другую сборку RutonyChat сохраните приложение и данные,
проверьте компиляцию native-скрипта против её SDK и изолированные тесты.
Затем проверьте загрузку расширения, панель, события, остановку и восстановление
на тестовой установке. Изменение runtimeconfig RutonyChat и замена frameworks
не входят в установщик расширения.

RutonyChat — стороннее закрытое приложение; его поставщик выбирает runtime
и выпускает обновления host. Проект расширения отвечает за собственный
пакет, зависимости и контракты. Совместимость с произвольной vendor-сборкой
не гарантируется только на основании синтетических тестов.
