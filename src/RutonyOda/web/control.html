Какие донаты передавать

Источники

Если сервис уже подключён напрямую к RutonyChat, его включение здесь может дать повторы.

Сохранение поставит передачу на паузу. Уже пропущенные события не восстанавливаются.

1. Своё приложение ODA

В кабинете ODA: API → Мои приложения. Создайте приложение, добавьте Redirect URI из строки ниже и сохраните изменения.

Client Secret берётся в настройках приложения. После сохранения поля очищаются.

2. Войти в ODA

Откроется обычная страница входа ODA. После входа вы вернётесь сюда. Передачу донатов затем нужно включить кнопкой выше.

Включённая передача сохраняется после перезапуска. Пауза отключает приём; очередь хранит сообщения до 24 часов. Полная история прошлых донатов не импортируется.

Нужно решение по доставке

RutonyChat мог уже обработать эти донаты. Автоматический повтор остановлен. Проверьте оповещения и выберите решение для каждого ID.

Неподдержанное сообщение

Полученные данные не прошли проверку. Можно оставить передачу на паузе и обратиться за исправлением либо явно пропустить одно сообщение.
